# Sputnik Accounting

Новое тестовое бухгалтерское приложение для Sputnik Mongolia.

## Важно

Старое приложение `sputnik-payroll` пока не изменяем.
Это отдельный проект.

## Этапы

1. Каркас приложения
2. Сбор исходных данных бухгалтерии
3. План счетов
4. Начальные остатки
5. Ерөнхий журнал
6. Банк / касс / НӨАТ
7. Зарплата
8. Отчёты и Excel
9. Сверка с фактической отчетностью
10. Только после проверки — переход на новую систему

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## База данных

На первом этапе бухгалтерские данные не сохраняем.
После согласования структуры подключим PostgreSQL.
Не используем локальный SQLite как постоянную облачную бухгалтерскую базу.
